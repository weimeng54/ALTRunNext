## 明确差异

- 默认使用 Alt+R 呼出，Ctrl+Alt+L 打开最近项目。可在设置的「快捷键」页录制其他组合。Windows 拒绝注册时会在面板中提示。
- 正式构建默认执行用户选择的命令；`--safe-mode` 禁止执行。Debug 默认预览，`--enable-launch` 可显式启用。无界面转换和迁移始终不执行导入命令。
- 参数 URL 编码保留原版规则，包括将数字编码为 `%31` 等；系统 ANSI 编码无法表示的字符明确报错，可选择 UTF-8 类型。
- 自定义语言使用“中文界面原文=译文”格式，提供中文和常用界面英文；语言在下一次启动生效。旧语言文件副本保留，原资源键名不直接冒充兼容。错误详情可能使用原始中文或系统语言。
- WinCtl 的常用 MinAll、UndoMinAll、Hide 和无参数恢复行为有原生实现；其他子命令继续调用原外部工具，缺失时明确报错。用户自己的 MyCmd、脚本和外部工具仍保留原调用能力，迁移不擅自复制这些二进制。
- 迁移读取磁盘快照；原版尚未保存到磁盘的编辑不能凭空迁移。同名偏好按文件顺序关联，差异写入报告。旧 HandleID 保留在原副本，不复用失效窗口句柄。
- 输入框和管理列表向系统提供文字，保留原生键盘、IME 和可访问性；不复制旧程序的崩溃、静默截断、随机并列顺序或强制清空工作集。

## 本地数据格式

TSV 向后读取四/五列；保存扩展为九列：快捷字、名称、命令、基础频率、参数类型、稳定 ID、工作目录、条目类型、启用标志。稳定 ID 在编辑和重排后保留，重复快捷字允许，重复 ID 拒绝。

`*.settings.ini` 和 `*.state.tsv` 随数据文件存放。记录保存由单个后台写入器串行合并，使用同目录暂存文件、刷新、替换与 `.bak`；发现外部变更时不覆盖。临时文件失败不会删除其他程序的文件。原版源文件保持只读。

性能以用户实际手感验收；合成回归、内存/GDI/USER 增长检查用来找缺陷，不再进行桌面帧采样或要求统计性能逐项不退步。
