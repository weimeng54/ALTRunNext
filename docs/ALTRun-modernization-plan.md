# ALTRun 现代化重写完整方案与原型说明

日期：2026-11-07。状态：供确认的设计方案；产品尚未实现，工具链尚未安装。

执行路线更新：用户已创建公开 GitHub 项目 `weimeng54/altrun`；采用 GitHub Actions Windows 云端构建，本机不安装 Rust/MSVC/SDK，仅在 D 盘编辑源码、下载包和验证。当前执行顺序见 [云端构建执行计划](superpowers/plans/2026-11-07-altrun-cloud-build.md)。本轮只更新计划，没有接入或推送远程。

## 1. 目标与设计结论

为已经使用 ALTRun 多年的 Windows 用户重写启动器：保留快捷字、参数命令和键盘操作习惯，解决现代 Windows 下的可靠性、Unicode 和 DPI 问题，提供清晰、紧凑的界面。优先级依次为：常驻资源极低、旧功能完整、现代 UI。

推荐 Rust + Win32 + Direct2D / DirectWrite，首发 Windows 11 x64 便携版。主程序采用事件驱动；设置、迁移及维护功能按需加载。不引入 WebView、常驻网络服务、云账户、插件宿主或全盘索引。UI 交互原型仅以 HTML 表达设计，正式产品不使用 HTML 或浏览器引擎。

当前目录已有设计文档与界面原型，无原生产品实现，也没有首次提交。本地 origin 指向 Gitee；GitHub 远端内容与写权限尚待验证。已阅读上游仓库文件树、发布记录、配置、英文语言文件、快捷项管理与匹配等部分源码；尚未运行旧程序，未用用户真实配置验收。因此本方案是可执行的设计基线，不能声称已证明“全部功能兼容”。任何新增发现都必须进入功能对照表，不能默默省略。

### 备选方案

| 方案 | 收益 | 成本 | 决策 |
|---|---|---|---|
| Rust + 原生 Windows API | 无浏览器运行时，控制资源，核心内存安全 | 文本输入、UIA、原生控件样式需要投入 | 推荐方案，待用户确认 |
| C++ + 原生 Windows API | 同样可低占用，Windows 工具生态成熟 | 内存与资源生命周期管理负担较高 | 保留备选 |
| C# + WinUI 3 | 现代控件完整，开发效率高 | 常驻预算需原型验证 | 若低占用目标放宽时重新评估 |
| Rust + Tauri | UI 开发方便 | Windows 使用 WebView2，不适合本项目首要目标 | 不采用 |

“现代技术栈”落实为受维护的语言、工具、Unicode API、明确的资源生命周期和自动化验证；不要求每个底层 Windows API 都是新接口。

## 2. 原版功能与兼容策略

基线为 etworker/ALTRun v1.46.7。建立 `功能 → 源码位置/旧版操作 → 输入样例 → 预期行为 → 新版实现 → 验收证据` 的功能矩阵。完整审计阶段覆盖全部窗体、事件处理、特殊标记、启动参数和配置读写，不仅核对菜单文案。

| 功能域 | 正式版本交付要求 |
|---|---|
| 呼出与驻留 | 主/次全局热键，原默认 Alt+R / Pause；最近项目热键；托盘菜单；自启动；发送到；单实例和再次启动传参 |
| 匹配 | 旧版前缀/任意位置匹配、通配符转换、正则可表达的行为、大小写处理、空查询、无匹配及前十项限制 |
| 排序 | 使用频率、匹配位置、快捷字长度、上次选择、最近列表；建立固定数据的排序回归样例 |
| 快速操作 | 上下键、翻页、Tab/Shift+Tab、Enter/Space、数字索引两种顺序、分号/单引号、鼠标滚轮和中键；核对修饰键语义 |
| 参数 | 无参数/原样/旧式 URL/UTF-8 URL 四种类型；参数对话框、历史与上限；参数内引号、空格、中文和特殊字符 |
| 模板 | `%p`、`%c`、环境变量、工作目录、相对路径、前台窗口标记及全部其他特殊语法；执行前捕获前台窗口信息 |
| 命令执行 | 应用、文件、目录、URL、脚本及系统命令；复制命令、打开目录；区分原生程序参数与显式 Shell 命令 |
| 管理 | 添加、编辑、删除、文件拖入/发送到、重复项处理、失效检查、批量路径转换、文本配置维护与备份 |
| 外观 | 字体、配色、宽度、透明度、背景图、圆角、显示项、声音与语言；提供现代主题和可关闭的外观选项 |
| 生命周期 | 启动通知、启动时显示、执行后隐藏/退出、延迟隐藏及唯一匹配自动执行，按原配置迁移 |
| 特殊命令 | 系统入口、网页搜索、剪贴板搜索、窗口显示/隐藏等依赖外部工具的行为逐项复核 |

关键规则：

- **行为兼容优先。** 默认“旧版兼容”匹配；增强名称搜索为可选模式，不能改变导入用户的默认排序。原型按快捷字过滤，尚不代表已实现旧版完整正则与频率排序。
- 旧正则实现与 Rust 正则引擎并非完全等价。审计反向引用、环视、转义及旧通配符预处理；使用隔离的兼容匹配器实现已确认语义。需要回溯的模式运行在按需工作进程，设置资源/时间边界；超限显示明确错误，不能退化为另一种匹配而不告知。
- 兼容用户可观察的功能与操作，修复崩溃、乱码、越界等缺陷。失效网站、已移除系统程序作为待修复项目展示，不能把新网站悄悄写进原命令。
- `WinCtl.exe` 等外部依赖目前未在仓库中发现实现。常用的窗口显示/隐藏能力计划以 Windows API 内置重写；保护窗口、提权窗口或已经失效的句柄给出明确结果。它们通过对照验收前不能标记完成。
- 无法迁移的外观值或特殊项列入报告，保留原文和导出；现代主题不声称逐像素还原旧皮肤。
- 如果某项不能实现，应保持未完成状态并披露，不能把第一阶段称为“完整复刻”。

## 3. 原型与界面规格

原型文件：`design/altrun-prototype.html`。原型的全部数据是示例，不扫描文件、不注册系统热键、不读取剪贴板、不执行命令，编辑只保留在本次预览。它是设计评审用交互稿，不是桌面软件，也不是性能证明。

视觉方向按用户反馈修订为“主要用于启动，平时不看 UI；元素和内容参考原版”。中性灰表面、清晰字体、小尺寸浮窗，保持原版字段与相对位置。避免宣传页、大面积毛玻璃、持续动效和无用数据面板。

### 启动面板

- 默认宽 420 DIP，允许调整并受当前显示器工作区限制；默认紧凑行高 20 DIP，可选 24 DIP，最多显示 10 项，其余原生滚动；少结果时自然收缩，不留固定空白。原版设计宽 420px、列表 ItemHeight=16px；新版使用 DIP 并保留现代 DPI 支持。
- 按原版主窗体结构显示顶部当前选中项名称、输入框内操作提示、编号/参数星号/快捷字/名称列表、底部单行 CMD。目录名称按原行为加方括号。去掉上一稿新增的图标列、逐行路径、类型标签、结果分组计数、品牌标语和底部操作栏。
- 保留原版显示命令行/操作提示/管理按钮/配置按钮/隐藏按钮开关。预览默认命令行和提示开启，工具按钮关闭，后者与仓库示例 INI 一致；用户导入时以实际旧配置为准。管理和设置通过 Alt+S / Alt+C 或托盘进入。
- 结果单击仅选中，双击或中键执行，按原版语义；不是上一稿的单击即启动。列表主要匹配快捷字，原型也按快捷字过滤；名称增强搜索维持可选，不默认开启。
- 呼出后输入框获得焦点，记住此前前台窗口；根据设置在鼠标所在或上次使用的显示器显示，确保不落在移除的显示器外。
- Enter 执行；有参数的项目进入参数输入；Space、数字和特殊键遵守兼容配置。IME 组词期间不执行、不自动唯一匹配运行。
- Esc 先取消组词，其后按已审计的旧版清空/隐藏行为处理；新增用户默认空查询隐藏。Tab 跳选只在启动面板的兼容输入场景生效，不抢夺设置表单的 Tab。
- 无匹配显示“添加命令”；命令执行失败后保留输入和选中项并显示原因。清空按钮立即响应。后台结果带查询序号，旧结果不得覆盖新结果。
- 默认不绘制持续动画；输入本地搜索不引入 300ms 网络防抖。可中断的短动画不超过 100ms，减少动态效果模式全部关闭。

### 参数输入

- 显示命令名称、参数框、近期参数与执行预览。参数编码类型沿用命令定义；旧式 URL 编码按导入来源编码复原，不能统统转成 UTF-8。
- Enter 确认，Esc 取消并返回原输入/选中项；取消与输入错误都不会执行命令。保留命令原本允许的空参数行为，按命令定义验证。
- 原型只演示参数对话框、校验和百分号编码预览，未实现历史或真实旧编码。

### 命令管理

- 正式窗口默认 1000×700 DIP，左侧列表，右侧非模态编辑器；窗口变窄后改为上下布局。大列表使用虚拟化；非浏览器生产界面不采用网页分页。
- 字段为快捷字、名称、命令、参数处理；高级设置折叠展示工作目录、执行方式等。原始命令字符串保持可查看。
- 新建/编辑共用字段校验与保存行为；成功保留筛选并选中该项；取消恢复上次保存内容；有未保存修改时离开先提供继续编辑/放弃。稳定 ID 唯一，快捷字不作为数据主键；导入的重复快捷字保留原顺序与行为，不因重复自动停用。普通新建默认提示重复，用户可明确选择保留两项；原型只展示默认拒绝重复的简化路径。
- 删除仅删除快捷项，不删除目标文件；可恢复的单项删除提供撤销。批量清理先检查和预览，明确数量，再确认写入。禁止“检查”直接删除。
- 缺失路径异步检测，网络路径超时标为“未确认”，不当成文件不存在。失效项可定位、编辑或停用。

### 偏好设置

- 常规、键盘与匹配、外观、兼容与数据四组；高级原版开关均有归属，避免为了简洁删除能力。
- 默认跟随系统主题，也提供浅色、深色；系统字体，不下载字体包。高对比使用系统色。
- 主热键默认 Alt+R，次热键 Pause。注册冲突显示冲突状态，旧热键直到新注册成功后才替换；录制控件与普通输入分离。
- 本地偏好按修改保存，失败显示“未保存”和重试；开机启动/发送到等涉及系统集成的操作显示实际成功状态。原型的切换只影响预览。
- 可完全通过键盘访问；自绘列表提供 UI Automation 的名称、选中、执行与滚动能力。原生 Unicode 输入框承担输入法、选择、复制及候选窗定位。

### 迁移向导

- 选择旧目录 → 只读解析 → 报告可导入/待检查项 → 冲突处理 → 写入新的 Data 目录 → 给出结果和回退入口。
- 报告覆盖编码、重复快捷字、目标缺失、未知语法、外部依赖及无法映射的皮肤项。原型的 128/3 等数值均为示例。
- 无法解析或执行的项目可修复或暂时停用；未解决项默认停用并保留原文。重复快捷字本身不视为执行错误，保留各自的稳定 ID、频率、原顺序与匹配结果；历史映射有歧义时才要求逐项选择，不覆盖旧条目。

## 4. 技术架构与内部接口

正式程序只有 Windows 11 x64 目标，不承诺 Windows 7/10 或跨平台；ARM64 留待需求明确后单独适配。

```text
Win32 消息循环 / 全局热键 / 托盘 / 单实例 IPC
                  ↓
控制器：输入与焦点、查询版本、选中、执行状态
          ↙                         ↘
快捷项与排序核心                  原生界面
解析/参数/兼容/历史              Direct2D + DirectWrite
          ↓                       Unicode 原生控件 / UIA
Windows 平台适配：Shell、进程、窗口、剪贴板、路径
          ↓
文本持久化与原子替换 / 本地备份
```

- UI 线程保持消息循环、控件和渲染状态，不进行磁盘遍历或阻塞 Shell 调用。按需启动有界任务；没有任务时工作线程可退出。
- 小型普通匹配可在内存同步执行；超过时间预算的查询转后台并取消过时任务。图标、快捷方式解析、网络路径与复杂兼容正则采用限时任务或按需辅助进程。
- 主程序默认非管理员；单命令提权通过系统 UAC。只有显式 Shell 命令经过命令解释器，普通程序执行不隐式拼到 `cmd /c`。
- 隐藏状态暂停动画/绘制；图标缓存有上限；按需释放绘制资源，GPU 内存单独测量。资源释放策略以唤醒延迟和驻留预算共同决定。
- Windows FFI、COM、句柄、回调都封装在平台层，采用 RAII；不能因使用 Rust 而宣称 Windows 边界无风险。

内部能力边界（没有 HTTP 服务或外部公共 API）：

| 接口 | 输入 → 输出与约束 |
|---|---|
| `LegacyImporter.preview` | 旧目录、编码提示 → 迁移草案和逐项问题；只读，不自动运行命令 |
| `CommandStore` | 快捷项、设置、历史 → 原子保存结果；单写入者、失败保留旧文件 |
| `SearchEngine.query` | 查询、兼容设置、使用记录、查询序号 → 有序结果/可解释错误 |
| `TemplateResolver.resolve` | 命令、参数、剪贴板/前台窗口快照、便携目录 → 执行计划或错误 |
| `PlatformExecutor.execute` | 明确类型的执行计划 → Shell 接受/进程创建结果；不声称目标应用业务执行成功 |

执行计划区分程序与参数、文件/目录、URL、显式 Shell、内置窗口操作。环境变量展开与模板替换按旧版审计确定先后顺序，使用回归样例锁定，避免 `%p` 与 `%PATH%` 冲突。操作日志默认不记录剪贴板、参数原文和完整敏感命令。

候选依赖限于 `windows`、`serde`/`serde_json`、必要的文本编码与匹配库。兼容正则依赖在审计语法后选定，不能为方便预先删减语义。依赖版本用 lockfile 固定；不为计时器或少量异步任务引入完整应用框架。

## 5. 数据、迁移与可靠性

采用便携模式，应用自有数据位于程序旁的 `Data` 目录。目录不可写时明确提示迁移到可写位置，不悄悄退回 C 盘 AppData。没有云同步、遥测或自动联网轮询。

初始新格式：版本化 UTF-8 JSON，设置、命令、历史分开；使用稳定命令 ID，顺序独立于名称。快捷项保留原始命令、参数类型、频率和启用状态；导入来源及未识别原文放在迁移报告中。历史按上限截断，批量合并写入，不为每个按键写磁盘。

兼容输入包括 `ALTRun.ini`、`ShortCutList.txt`、`FavoriteList.txt` 及旧程序引用的参数历史/其他数据文件；后者须在完整源码审计中确认，不虚构文件名。自动识别 BOM/有效 UTF-8，其他编码提供 GBK、系统代码页等明确选择与文本预览；有歧义时不能静默替换为乱码字符。

原始文件只读保留。导入输出使用全新目录与迁移报告；写入前做备份，临时文件和目标同盘，写完刷新后原子替换，保留最近 10 个配置版本。频率/最近记录有界合并保存；退出时尽力刷新，崩溃最多丢失尚未刷新的近期记录，不丢命令配置。

允许手动导入/导出旧文本格式，并明确新格式无法表达为旧语法的条目。不支持两套格式同时作为可写真源。为保留文本编辑习惯，提供“编辑配置文件”，外部修改后校验并重载；与未保存编辑冲突时要求选择重载或保留副本。

全局命名互斥体保证单实例；第二次启动通过受限的本用户 IPC 转交“发送到”或呼出请求。坏数据隔离到问题列表；配置整体损坏时提供恢复备份入口，不静默重置为空。诊断记录有大小与轮换上限；故障转储由用户显式开启，存入便携 Data 目录。

回退方式为退出新版，再启动未改动的旧目录。新版不覆盖原版配置，不自动争抢旧程序已经占用的热键。

## 6. 开发环境与下载策略

**当前采用云端编译，不执行本机安装。** GitHub Actions 标准 `windows-2025` runner 负责编译、单元/集成测试及打包；用户电脑只保留 D 盘源码、下载包、便携 Data 与验收报告。公开仓库标准 runner 按 GitHub 当前规则免费；不选付费 larger runner，也不创建本机 self-hosted runner。工作流、权限、镜像回退、缓存和产物保留见新版执行计划。

本节下列 `D:\rust` 目录和 MSVC 安装说明仅作为历史备用方案，当前不创建、不安装；只有用户以后明确选择本机构建时才重新评估。**它们不属于当前执行步骤。**

```text
D:\rust\
  rustup\             Rust 工具链与 rustup 状态
  cargo\              cargo、依赖下载与 registry 缓存
  build-tools\        可指定位置的 MSVC 工具
  sdk\                可指定位置的 Windows SDK 文件
  downloads\          下载与安装介质
  temp\               本项目安装/编译子进程的 TEMP、TMP
  target\altrun\      Cargo 构建输出
  scripts\            环境与构建入口（后续阶段才创建）
D:\altrun\            项目源码、设计和发布产物
```

后续通过项目启动脚本设置 `RUSTUP_HOME`、`CARGO_HOME`、`CARGO_TARGET_DIR`、`TEMP`、`TMP`，避免修改全局 TEMP；rustup 使用最小配置，不自动下载本地文档，并固定经过验证的 stable 版本。运行目录与工具链目录分离。

镜像优先级：Rust 工具链/依赖默认使用 RsProxy 的 Rustup 镜像与 sparse registry；工具链备用 USTC；版本、包校验及 Cargo.lock 保留。镜像缺少固定版本时提示或回到官方可信源，不关闭证书校验、不换未经核实的第三方二进制。MSVC/Windows SDK 以微软签名分发为准，优先检查可用的官方国内 CDN，不承诺存在可信国内镜像。

**MSVC 和 Windows SDK 不能保证 C 盘零写入。** 微软安装器、共享组件、系统服务或系统管理的缓存可能落到系统盘。安装预检必须先列出 D/C 两盘所需空间；本方案不把“尽量放 D 盘”解释成用户同意占 C 盘。未确认可接受的系统盘占用前不启动安装。

如果“工具新增文件不得占 C 盘”是硬约束，默认改为外部 Windows 构建机/CI 编译，本机只运行便携成品；这需要用户提供或连接构建服务。便携 GNU/LLVM 工具链可作为另行验证的备选，但在验证 Windows API 链接、SDK 覆盖和调试支持前，不承诺可无损替代 MSVC。Windows/杀毒/系统日志自身的磁盘写入不在应用可完全控制范围内。

## 7. 资源预算与性能验收

以下为工程目标，尚无原生成品实测。测试使用 Release x64，固定 Windows 11 版本、硬件、DPI 和命令样本；样本为 1 万条本地快捷项，不含全盘索引。记录冷/热状态、每次测量次数及版本。

| 指标 | 初始验收目标 | 测法 |
|---|---|---|
| 隐藏待机私有提交 | ≤30 MiB | 稳定 60 秒后，统计自身所有进程 Private Bytes |
| 隐藏待机工作集 | ≤60 MiB | 不主动裁剪工作集；单列共享部分与 GPU 内存 |
| 面板显示私有提交 | ≤50 MiB | 常用图标缓存热状态；打开设置另列峰值 |
| 隐藏待机 CPU | 5 分钟均值 <0.1% 总 CPU | 记录采样精度，无忙轮询和周期性明显尖峰 |
| 热键到首帧 | P95 ≤100 ms | 100 次热唤醒，以热键接收到可见绘制时间计 |
| 输入到结果呈现 | P95 ≤30 ms | 1 万条样本、200 次普通查询；兼容复杂正则单列 |
| 冷启动至可接收热键 | P95 ≤500 ms | 20 次，无首次杀毒扫描等外部噪声时；首启单列 |
| 稳定性 | 24 小时压力运行无崩溃/死锁 | 重复呼出、搜索、执行模拟与维护；观察 Private Bytes、GDI/USER 句柄和线程数 |

长期稳定的判定不能只看最后一个数字：在预热后分段记录，末段私有提交相对稳定基线不应出现持续上升趋势，累计增量目标 ≤5 MiB；句柄数应回到稳定范围。设备/字体/驱动共享内存单列解释，不藏在“总内存”之外。严格资源目标未达时先修架构或明确权衡，不只换统计口径。

## 9. 测试场景与发布标准

- **核心回归**：空/长/特殊字符查询、中文/英文、所有匹配开关、相同频率与排序边界、旧通配符/正则、记忆首选、数字索引和唯一匹配开关。
- **参数执行**：空格、引号、Unicode、`%`、`&`、换行、环境变量、多占位符、剪贴板不可用、网络路径、相对路径、不同工作目录、无效 URL、UAC 取消和启动失败。
- **迁移**：UTF-8/GBK/系统代码页、空/坏/旧版文件、注释和空行、重复快捷字、`|` 等分隔符、未知类型、外部依赖、失效路径、只读目录、保存中断、备份恢复和外部编辑冲突。
- **Windows 行为**：热键冲突、单实例转交、登录启动、Explorer 重启后恢复托盘、休眠/解锁、多屏插拔、100/125/150/200% DPI、RDP、设备丢失后重建绘制资源。
- **可访问性**：微软中文输入法组词/候选框/Enter、全键盘、Narrator、系统高对比、长名称、主题切换，所有自绘结果项有 UIA 语义。
- **UI 状态**：成功、无结果、空列表、检查中、部分失败、保存失败、热键注册失败、未保存离开、批量操作预览、撤销与恢复。
- **性能**：与原版在同一台机器、同一数据集对比；资源预算、1000 次以上呼出/隐藏、重复打开设置/管理器、1 万项查询与 24 小时长稳。
- **工程检查**：`cargo fmt --check`、`cargo clippy`、核心单测、迁移金样、执行计划单测、Windows 原生集成测试、Release 构建；发布前检查依赖与资源许可，确认原版素材是否允许复用，优先自行实现并设计图标。

## 10. 本次交付边界与仍需验证的事实

本次交付完整设计、可交互的界面原型和检查记录。没有安装 Rust/MSVC/SDK、没有注册热键或修改系统启动项、没有运行旧版或实现新桌面程序。原型通过浏览器校验也不代表 Windows 原生 UI、中文输入法和性能预算已经通过。

仍需后续验证：原版所有事件/特殊语法、实际配置规模与编码、WinCtl 等外部工具行为、系统盘安装占用、原生 UI 的实测资源、旧素材授权。它们已经安排在功能审计与原生验证阶段，不作为隐含的已满足假设。
