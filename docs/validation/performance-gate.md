# 性能门槛与进度

## 约束

用户批准的当前计划优先于早期文档中的固定预算：以本机原版 ALTRun 的同数据、同负载测量为基线。100ms 呼出 / 30MiB 内存不再是合格线；不可重复证明不劣于原版时，不扩大功能或宣称完成。

基线覆盖呼出、立即输入、连续搜索、选择执行、长闲置后首次响应；记录中位数、P95、P99和异常长尾，配对比较；同时记录 Private Bytes、工作集、CPU、句柄和线程。后台繁忙、真实输入法与长时间运行分别验证。

## 试验包边界

- `altrun-probe.exe`：Ctrl+Alt+R 呼出，保留原版 Alt+R/Pause。默认 Enter 只隐藏窗口，不执行导入命令；可选安全启动只允许系统目录的记事本。搜索暂为普通别名匹配，尚无旧版完整正则、参数和配置管理。
- `altrun-measure.exe`：局部观测工具。只向已验证进程/窗口发送热键、固定查询和定向 Escape，不发送 Enter；捕获结果区像素的时间区间。两侧必须执行相同查询序列，参考图不稳定或动作前已匹配预期时拒收。
- 软件热键起点、WM_SETTEXT 搜索和桌面截图只能提供局部时间上界，不能替代物理输入、IME、硬件呈现或闲置后验证。因此该工具的输出固定为 `pending`，不能自动打开功能开发门槛。
- 真实数据只在本地忽略目录；云端原生测试使用合成数据。

## 观测器自身的验证

用户随后完成同权限运行，程序在正式 `observe()` 阶段报告未观察到预期结果像素。旧观测器未保存中途记录，无法判断此前完成了多少观测，也无法从该错误归因原版或候选性能。

因此先验证观测器，暂不要求重复原版测试：

- 失败仍保存 `pending/rejected` JSON，记录目标、阶段、轮次、query_id 和此前完成的观测；部分记录不能直接用于验收统计。
- 超时额外记录可见、前台、几何、哈希及捕获期间几何稳定性；参考像素只留内存，落盘仅含差异计数与边界坐标。
- `--probe-only-replay` 完全跳过原版进程与热键，只对自建候选窗口执行同一套严格 `prepare → observe`，使用 12 条合成快捷项，输出种类固定为 `observer-self-replay`，决策仍为 `pending`。
- 失败留证、中途故障、原版隔离、像素差异分类都已观察到 RED→GREEN。提交 `0502a41659e46529ccb20761c6ab2efd0a08f9e4` 的 [构建与全部检查](https://github.com/weimeng54/altrun/actions/runs/42472199317) 成功，产物已核对 SHA256 和源码提交号。

独立回放已复现失配：一次运行保存了 6 条观测，随后在窗口、前台和几何检查相符时未匹配完整哈希；后续运行也遇到准备阶段前台变化。由此可以独立排查观测器，无需将原版作为反复试错对象。完整区域在短列表时包含 CMD 行及窗外背景，其稳定性仍须验证；目前没有据此放宽哈希条件或宣称性能通过。

操作者确认约 20 秒不操作键鼠、不切换窗口后，同一 `0502a41` 版本的合成回放完成了 3 轮、15 次严格观测，记录为 `observer-self-replay / observed / complete / pending`；已复核每轮 5 条、目标只有自建 probe、所有时间区间下界不大于上界。这只证明观测器在该次受控条件下完成回放，不证明此前失配的唯一根因，也不代表原版对照、硬件呈现、IME 或长期资源验收通过。

## 停用跨次固定参照图

一次受控原版重跑仍在首个非空查询失配，差异全部位于列表内部，前台、尺寸和捕获期间几何检查相符。进一步核对发现，[上游排序实现](https://github.com/etworker/ALTRun/blob/master/Unit/untShortCutMan.pas#L1830) 对较大结果集采用随机枢轴的非稳定快排，同分项可以有不同合法顺序。本地模型以同一输入和分数回放不同枢轴路径，确实产生多种正确的前十项顺序。因此一次预热截图不能作为后续同查询的唯一正确参照；这不是原版迟滞的证明。

新版观测器改为记录本次动作后的画面序列，区分首次观测到本次最终哈希的上界与最后稳定匹配段的上界。仅 CMD/边框变化而列表不变、画面未变化、前台中断、潜在遮挡或采样过稀都会拒收；采样期间发现鼠标位置变化也会排除该次观测。采样区位于当前窗口内，从列表顶部到窗口底部，不含编辑框光标和窗外桌面。

观察结束规则为至少采集 200ms，再要求两次以上一致观测的保守跨度至少 50ms；它是观测器选择参照的规则，启动器仍立即处理输入。稳定跨度不包含首尾截图调用的不确定部分，并同时记录帧间间隔、单次捕获宽度和相邻采样跨度。

**这些数据仍不是内容正确呈现的验收证明。** 报告明确保留 `content_verified=false`、`decision=pending`，原版对照种类为 `pixel-settling-observations`；逻辑查询/计数/选择验证和像素变化不足以独立证明所有字形已经正确绘制，遮挡检查也只是采样检查。不得将其冒充硬件呈现、物理输入或完整性能门槛通过。
