# 性能门槛与进度

## 约束

用户批准的当前计划优先于早期文档中的固定预算：以本机原版 ALTRun 的同数据、同负载测量为基线。100ms 呼出 / 30MiB 内存不再是合格线；不可重复证明不劣于原版时，不扩大功能或宣称完成。

基线覆盖呼出、立即输入、连续搜索、选择执行、长闲置后首次响应；记录中位数、P95、P99和异常长尾，配对比较；同时记录 Private Bytes、工作集、CPU、句柄和线程。后台繁忙、真实输入法与长时间运行分别验证。

原版在运行，启动路径位于 D 盘。先前一次短采样为 Private Bytes 15.75 MiB、工作集约 0.48 MiB、5 秒 CPU 约 0%；这是状态快照，不是响应性能基线。

2026-11-07 只读验证 GitHub 目标仓库 refs 为空；Gitee origin 保留。尚无新程序的性能数据。

本轮 30 秒采样共 138 点：原版 Private Bytes 15.7734 MiB、最大工作集 3.1563 MiB，采样 CPU 均值 0%。真实快捷项文件是 GB18030 编码，95 行中解析出 91 个条目，未解析非空行 0；转换数据仅在忽略目录，不公开内容。

云端已验证 4 个 Rust 核心测试先失败；随后编写实际实现。6 个本地 Python 门槛测试已完成 RED→GREEN，验证 P99/资源退步会失败，缺少真实呈现、输入法、长闲置或 24 小时数据不能通过。

用户确认原版手动 Alt+R/Pause 正常。桌面助手未捕获窗口属于观测限制，不能据此判定原版有缺陷；消息处理时间也不等于真实呼出/首帧时间。

绘制实验选用常驻原生 EDIT/LISTBOX + GDI，而不是先初始化 Direct2D：当前只有十行文字，优先复用与旧版相近的薄路径并实测。它是可推翻的性能实验，不是绕过门槛的框架承诺。

提交 `05c263e34e38c1fa6c753211b36b9bb31484b99d` 已通过标准 Windows 云端构建：4 个核心测试、2 个原生窗口回归测试、9 个 Python 证据校验测试，以及 clippy 和只读格式检查。测试曾复现并修复结果点击后输入焦点丢失、可选安全启动的路径搜索风险，以及非有限数值绕过证据校验的问题。编译成功不代表性能通过。

## 试验包边界

- `altrun-probe.exe`：Ctrl+Alt+R 呼出，保留原版 Alt+R/Pause。默认 Enter 只隐藏窗口，不执行导入命令；可选安全启动只允许系统目录的记事本。搜索暂为普通别名匹配，尚无旧版完整正则、参数和配置管理。
- `altrun-measure.exe`：局部观测工具。只向已验证进程/窗口发送热键、固定查询和定向 Escape，不发送 Enter；捕获结果区像素的时间区间。两侧必须执行相同查询序列，参考图不稳定或动作前已匹配预期时拒收。
- 软件热键起点、WM_SETTEXT 搜索和桌面截图只能提供局部时间上界，不能替代物理输入、IME、硬件呈现或闲置后验证。因此该工具的输出固定为 `pending`，不能自动打开功能开发门槛。
- 真实数据只在本地忽略目录；云端原生测试使用合成数据。

## 最近一次可复核结果

`cad06c0db66411510398bd77ea075bdc376d8de9` 的 [GitHub Actions 构建](https://github.com/weimeng54/altrun/actions/runs/42367344710) 成功：只读格式检查、15 项测试、clippy、两个 Release 二进制均通过。下载产物已逐个核对 SHA256，并核对 COMMIT.txt；本机没有安装 Rust/MSVC/SDK。

窗口识别失败的原因已查明：命令执行器位于 CodexSandboxDesktop，原版位于用户交互桌面。跨桌面枚举失败不是原版故障，也不是性能数据。没有切换或修改系统桌面隔离设置。

本地测试入口已实现：无参启动测量程序时，只读取同目录的显式三行私有 session 文件，启动同目录 probe 并加载本地数据；只试三轮，结束时回收自建子进程，保留原版。状态写入 session-status.txt，有效局部观测写入 session-result.json。入口新增代码已单独审查，无 Important/Critical 发现。

桌面工具请求启动最终产物时返回 `Computer Use app approval timed out`。随后确认没有测量/候选进程，也没有 session 状态文件。因此尚未取得任何有效同桌面延迟样本，不能给出中位数/P95/P99 对比或宣布性能达标。当前停在本机交互启动确认这一步；闲置、负载、IME、执行和长期资源验收均未完成。
