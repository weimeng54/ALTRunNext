# ALTRun Modern

Windows 11 x64 原生快捷启动器，Rust + Win32 / GDI。沿用原版的标题、输入、编号快捷字/名称和 CMD 结构，默认 420 DIP 紧凑面板。常用呼出和搜索使用常驻控件与内存数据，无动画、防抖、网络查询或图标读取。

双击便携包里的 `ALTRun.exe` 后按 **Alt+R** 呼出，Enter 启动。Alt+S 打开快捷项管理，Ctrl+L 查看最近启动。托盘右键提供打开面板、管理快捷项、设置和退出。在设置的「快捷键」页可以直接录制按键，在「常规」页可以开启或取消资源管理器的「发送到」入口。正式构建默认执行所选命令，`--safe-mode` 为预览模式。Debug 默认不执行，兼容 `--enable-launch`。

0.2 已接入完整设置、字面/通配符/正则搜索、频率/偏好/最近列表、四种参数类型及历史、剪贴板与窗口模板、工作目录和显示模式、文件拖入/发送到、管理维护、主题/字体/外观、单实例和完整迁移。具体入口、验证依据及差异见 [功能对照](docs/compatibility.md)。

数据保存在自己的 `shortcuts.tsv`，设置与记录存放在旁边。管理修改先保留草稿，保存成功才更新启动面板，并留下上一版 `.bak`。外部修改冲突和失败会保留草稿。原版快捷项、INI 和个人脚本不被改写。

完整迁移可在管理器工具菜单执行，或使用：

```text
ALTRun.exe --migrate "旧版目录" --output-dir "尚不存在的新目录"
ALTRun.exe --data "新目录\shortcuts.tsv"
```

只读转换单个快捷项文件：`--convert-legacy <源文件> --output <新文件.tsv>`。转换与迁移不执行命令。自动启动和发送到必须在设置中主动开启；仅使用新版自己的系统集成名称。

源码在 D 盘编辑，GitHub Actions Windows runner 编译、检查和打包；本机不安装 Rust、MSVC 或 SDK。国内镜像优先，不可用时回退同版本官方源。个人配置、路径、剪贴板和转储不进入仓库。
